## Phase Goal (user story)

**As a** resident who does not trust official civic-reporting channels, **I want to** capture a live geo-tagged photo of a local problem, tag its category, and publish it, **so that** anyone nearby can see photo-verified local issues in a proximity feed and open any report by its ID or permalink.

<objective>
Build out the discovery slice on top of the tracer feed: a polished proximity feed with cursor-paginated infinite scroll and all its states, the search-by-ID box, and the SSR permalink page — satisfying FEED-01, FEED-03, FEED-04.

Purpose: The Plan 02 tracer proved a single card renders; this plan makes the feed a real, browsable, shareable surface. It only touches the feed/permalink files (never the capture files Plan 03 owns), so both run in wave 3 in parallel.
Output: An anonymous, proximity-sorted, infinitely-scrolling feed with working search-by-ID and shareable permalinks.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/feed | Untrusted lat/lng + cursor; visitor location must not be persisted/logged |
| browser → /c/{id} | Public permalink; only the opaque public_id addresses a complaint (no enumeration, no identity leak) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | /c/{id} lookup + feed payload | high | mitigate | Lookup/render use only the opaque `public_id`; the serial `id` and `submitter_id` are never selected into any response — prevents IDOR/enumeration and identity leak. |
| T-01-05 | Information Disclosure | visitor location on /api/feed | medium | mitigate | Visitor lat/lng is used only to compute the proximity ORDER BY for that request; never inserted into any table or written to logs. |
| T-01-06 | Information Disclosure | poster identity on feed/permalink | medium | mitigate | Feed/permalink render the generic 'Reported by a nearby resident' label; submitter_id is excluded from all external-facing queries (D-06). |
</threat_model>
